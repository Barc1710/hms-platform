# 👨‍💼 HMS OmniHotel - Panel ERP (Admin)

Este es el **Panel Administrativo (ERP)** para el staff del hotel, desarrollado con [Next.js](https://nextjs.org/).

---

## 🛠️ Funcionalidades Principales

- **📅 Rack de Reservas:** Gestión visual de la ocupación hotelera.
- **🧹 Gestión de Limpieza:** Control de estados de habitaciones para Housekeeping.
- **💰 Control de Caja:** Apertura, cierre y movimientos de turnos de recepción.
- **👥 Gestión de Staff:** Administración de usuarios y roles del hotel.

---

## 🚀 Inicio Rápido

### 🔧 Instalación
```bash
pnpm install
```

### 🏃 Ejecución
```bash
pnpm run dev
```
